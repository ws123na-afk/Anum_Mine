# التقارير

تحفظ التقارير كل تقرير أُنشئ في مساحة العمل هذه، سواء أنشأته أنت أو وكيل أو أتمتة، مع مقاييسه الرئيسية وأبرز نقاطه وبياناته. يمكنك إنشاء تقرير جديد أو تنزيله أو إرساله بعد موافقة مالك.

## أنشئ تقريرًا

1. افتح **التقارير** من الشريط الجانبي.
2. ضمن **إنشاء تقرير** اختر **التقرير** و**الفترة** و**من يمكنه رؤيته** (**مشترك مع مساحة العمل** أو **خاص بي**).
3. انقر **إنشاء الآن**. يُفتح التقرير الجديد.
4. لتكراره اختر **الجدولة** وانقر **جدولته**. ويفتح **إدارة الجداول** الأتمتة التي تشغّله.

## ابحث عن تقرير ونزّله

1. اكتب في **بحث** (العنوان أو الملخص)، أو صفِّ حسب **النوع** و**أنشأه**، ثم انقر **بحث**. ويعيد **مسح** ضبط المرشحات.
2. انقر عنوان تقرير لفتح مقاييسه وأبرز نقاطه وبياناته.
3. انقر **تنزيل CSV** أو **تنزيل Markdown** أو **طباعة أو حفظ PDF**. وينسخ **نسخ الرابط** رابط التقرير.
4. إن كنت تدير التقرير فأعد تسميته بـ **حفظ العنوان**، أو استخدم **مشاركة مع مساحة العمل** أو **جعله خاصًا**، أو **حذف**.

## أرسل تقريرًا بالبريد أو واتساب

1. افتح التقرير وانتقل إلى **مشاركة**.
2. اختر **البريد** (حدّد **من صندوق البريد** والمستلمين) أو **واتساب** (اختر محادثة مفتوحة للرد).
3. أضف **الرسالة** إن شئت وانقر **طلب الإرسال**.
4. يوافق مالك عليه في الموافقات، وعندها فقط يُرسل. ويأخذك **فتح الموافقات** إلى هناك.

## من يمكنه ذلك

- المالكون والأعضاء: إنشاء التقارير وجدولتها وطلب إرسالها (مع صلاحية البريد أو واتساب).
- المشاهدون: قراءة التقارير والبحث فيها وتنزيلها.
- إعادة التسمية والمشاركة والحذف لمنشئ التقرير، أو للمالك في التقرير المشترك. ولا يجعل التقرير خاصًا إلا منشئه.
- ينتظر الإرسال دائمًا موافقة مالك.
