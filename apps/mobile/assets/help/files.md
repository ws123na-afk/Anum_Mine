# Documents

Documents holds the files of this workspace that your agents can read. Text files are indexed for search so tasks and chat can use them.

## Upload a file

1. Open **Documents** in the sidebar.
2. Click **Upload** and pick one or more files. The size limit and accepted types are shown under the button.
3. Watch the progress bar. Click **Cancel** to stop an upload; nothing is stored.
4. Check the **Index** column: a text file is ready for tasks once it is indexed.

## Find and preview a file

1. Type part of the name in **Search files by name** and click **Search**, or change the sort.
2. Narrow the list with **File type** and **Index state**.
3. Click a file to see its **Preview** and details. Markdown can switch between **Show formatted** and **Show source**.
4. Click **Download** to save the file. **Load more files** shows the next page.

## Share, rename or delete a file

1. Open the file and click **Share link**, then **Copy link**. Anyone with the link can download the file for a few minutes, without signing in.
2. Click **Rename**, type the **New name** and click **Save name**. The extension stays the same.
3. If indexing failed, click **Re-index**.
4. Click **Delete**, then **Delete permanently** to remove it. This cannot be undone.

## Who can do this

- Owners: everything, including renaming and deleting any file.
- Members: upload and re-index files, and rename or delete their own uploads.
- Viewers: see, preview and download files, and create share links.
