# تخطيط الإطارات

يقرأ تخطيط الإطارات بيانات إطاراتك (مثل قاعدة بيانات TyrePulse)، ويتوقع متى يحتاج كل إطار إلى الاستبدال، ويحوّل ذلك إلى خطة شراء وتنبيهات وتقارير. يقرأ ANUM بياناتك فقط.

## اربط بيانات إطاراتك

1. افتح **تخطيط الإطارات** من الشريط الجانبي وانقر تبويب **الاتصال**.
2. ضمن **مصدر البيانات** اختر **نوع الاتصال**، واملأ العنوان وبيانات الاعتماد، وانقر **حفظ الاتصال** ثم **اختبار الاتصال**.
3. ضمن **الربط** انقر **اكتشاف الجداول** (أو **استخدام إعداد TyrePulse الجاهز**)، وراجع الأعمدة وانقر **معاينة على عيّنة**.
4. انقر **حفظ الربط** ثم **مزامنة الآن**. زامن مرة أخرى متى أردت أرقامًا محدّثة.

## اقرأ التوقعات وتعامل مع التنبيهات

1. انقر تبويب **لوحة المعلومات** لملخص الأسطول والإطارات المستحقة قريبًا.
2. انقر **التوقعات** وضيّق القائمة حسب **شهر الاستبدال** أو **الحالة** أو **الثقة**، أو ابحث بالرقم التسلسلي أو المركبة أو العلامة أو المقاس. ويحفظ **تنزيل CSV** القائمة.
3. انقر **خطة الشراء** لترى عدد الإطارات المطلوب شراؤها حسب الشهر والمقاس والعلامة.
4. انقر **التنبيهات** ثم **إقرار** بعد معالجة التنبيه. ويعيده **إعادة فتح**.

## أنشئ تقريرًا وأرسله

1. انقر تبويب **التقارير**.
2. ضمن **إنشاء تقرير** اختر **التقرير**، و**من** و**إلى** اختياريًا، وانقر **إنشاء**.
3. نزّله بزر **PDF** أو **CSV**.
4. لإرساله انقر **إرسال**، واختر **الإرسال عبر**، وأدخل المستلم وانقر **طلب الإرسال**. لا يخرج شيء حتى تتم الموافقة عليه في الموافقات.

## من يمكنه ذلك

- المالكون: كل شيء، ومنه ربط المصدر وبيانات الاعتماد والربط وافتراضات التخطيط وقطع الاتصال.
- الأعضاء: المزامنة، وإنشاء التقارير وجدولتها وحذفها وإرسالها، والإقرار بالتنبيهات.
- المشاهدون: قراءة لوحة المعلومات والتوقعات وخطة الشراء والتنبيهات والتقارير، وتنزيل CSV أو PDF.
