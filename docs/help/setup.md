# Setup plan

The setup plan sets up the whole business in one go: agents, skills, assistants, rules, knowledge folders, saved commands and automations. You see what will happen first, and nothing changes until you confirm.

## Preview a plan

1. Open **Setup plan** in the sidebar under **Admin**.
2. If the server has more than one plan, pick it under **Plan**.
3. On the **Plan** tab, choose **Pilot** (turns on only three agents to try things out) or **Whole plan**.
4. Read the figures, **Week by week** and **What the plan does here**. Narrow the list with **Search items**, **Section** and **Only changes**.

## Apply it

1. Tick **Replace my changes** only if anything you changed or removed after the plan added it should go back to the plan's version.
2. Click **Apply pilot** or **Apply whole plan**. **Nothing to change** means the workspace already matches.
3. Read the confirmation and click **Apply now**. Automations are added turned off, agents start with little freedom, and applying again never makes copies.
4. The result shows how many items had each outcome and lists any that failed, with the reason.

## Record pilot checks

1. Open the **Pilot checks** tab. Its header shows how many checks passed and whether the pilot gate is open.
2. Try each case with test accounts only.
3. For a check, pick **Pass**, **Fail** or **Not run**, then add a **Note** and the **Proof (a task or approval id, or an https link)**.
4. Click **Save result**. ANUM keeps who recorded it and when.

## Who can do this

- Workspace owners and organization administrators: see and preview plans, apply them and record pilot checks. Everyone else sees who can apply it and an **Open Members** button.
- Every applied item still goes through its own feature's permission checks and is written to the audit log.
