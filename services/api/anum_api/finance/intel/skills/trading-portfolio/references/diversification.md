# Diversification and portfolio theory

- **Diversification**: combining assets whose returns do not move together lowers the portfolio's volatility for a given expected return (Markowitz 1952). It does not remove market-wide risk.
- **Correlation changes**: correlations tend to rise in crises, so diversification helps less when it is needed most.
- **Concentration**: ANUM caps any one symbol at 25 percent of a paper portfolio's equity in Supervisor orders.
- **Rebalancing**: restores target weights; it trims what rose and adds to what fell, with trading costs each time.
- **Naive versus optimised weights**: estimated "optimal" weights are fragile; equal weights are a strong out-of-sample baseline (DeMiguel, Garlappi and Uppal 2009).
- **Benchmark**: compare a strategy with buy and hold of the same symbols over the same span, after the same costs. A broad index is the fairer benchmark for a diversified portfolio, but ANUM compares only with data it has stored.
- **Currency**: a portfolio in USD and one in AED are not comparable without a recorded exchange rate; ANUM never mixes them silently.
