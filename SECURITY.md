# Security policy

## Reporting a vulnerability

Please report security problems in ANUM privately by email to **info@shahzebrahman.com** with "Security" in the subject. Do not open a public GitHub issue for a vulnerability.

Include what you found, the steps or a proof of concept to reproduce it, the affected host, page or API route, and how we can reach you. Please do not access, change or delete other people's data, do not run denial of service or automated scans at a volume that degrades the service, and give us reasonable time to fix the problem before you share details.

We will acknowledge your report, keep you informed while we work on it and tell you when it is fixed. We do not run a paid bug bounty.

## Supported versions

Only the current `main` branch and the version deployed from it receive security fixes.

## What we already do

The public [Trust page](https://app.anum360os.com/trust) summarizes ANUM's security measures. The details, including the CI security scanners and reviewed exceptions, are in [docs/security.md](docs/security.md) and the [threat model](docs/threat-model.md).
